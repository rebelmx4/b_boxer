本仓库分为 客户端 和  服务端

客户端：electron + react + ts
服务器：python



服务端（server）（暂时不开发）：

1. 接收客户端消息，抓取当前游戏截图，返回给客户端



客户端（工程目录：client）

功能页签一：

1. 左边侧边栏 和 “图片展示操作 一体的区域”
2. 左边侧边栏顶部有一个加载按钮，可以选择加载一张图片
3. 图片自适应展示区域的大小
4. 用户最大可以放大图片 2倍，最小就是自适应展示区域时的大小
5. 可以在图片上画框，画的框 不能超过原图的边缘
6. 可以画多个框，每个框左上角内侧带一个唯一数字编号（从1开始）
7. 左侧边栏，依次展示 框 的编号，xywh（如1： X: 1239 Y: 166 W: 576 H: 766）。多个复制按钮，复制成不同的形式。
8. 复制python元组按钮，复制rect按钮：Rect(left=911, top=247, width=101, height=660)
9. 鼠标移入框内，然后按下左键就可以移动框
10. 鼠标移到框的边上或四个角，就可以左键拖到调整大小
11. 按住ctrl+鼠标左键 选中框边，使用 上下左右键 调整边，单位为未放大时的一个像素
12. 按住ctrl+鼠标左键 选中框，使用 上下左右键 移动框，单位为未放大时的一个像素
13. 平时 alt + 左键 移动原图。当时原图最小状态 也就是 最匹配画布时，不能移动原图

功能页签二：

1.  布局：左边侧边栏 + cor识别效果区域
2. 左边侧边栏 历史识别结果，可以点击查看
3. 侧边栏顶部固定一个不随历史是识别结果滚动的加载图片按钮
4. 加载图片按钮，发送图片给服务器
5. 服务区放回结果后，将原图横向或纵向扩展一倍，如果是宽图就纵向扩展一倍，如果是竖图就横向扩展一倍，扩展部分是白色，将识别结果box矩形框画出来，同时将文字写在框中，字号12号
6. 服务器地址http://10.20.6.31:8080/ocr，这个服务是一个三方服务，已经开发完毕。不是本工程的开发内容
7. 用ts直接发送参数和接收识别结果，ocr服务的 python 代码参考。
